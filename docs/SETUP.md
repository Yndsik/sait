# Подключение с iPhone

Изменения подготовлены для существующего сайта. До настройки окружения серверный Steam API закрыт и возвращает 503. Steam Web API Key для используемых Store endpoints не требуется. Они не гарантируют SLA; ошибки показываются в интерфейсе.

1. Supabase → Authentication → Users → открой свой существующий аккаунт → скопируй **User UID**. Не создавай новый аккаунт, чтобы сохранить связь с данными.
2. Supabase → SQL Editor → New query: вставь `supabase/migrations/202611060001_owner_workspace.sql`, замени `REPLACE_WITH_OWNER_UUID` своим UID и нажми Run. Скрипт сохраняет данные, заменяет политики таблицы `user_workspaces` доступом только владельца. Если таблицы нет, транзакция завершится ошибкой: сначала нужно проверить фактическую схему, не создавать пустую замену.
3. Supabase → Authentication → Sign In / Providers → Email: выключи **Allow new users to sign up**. Удаление кнопки в интерфейсе само по себе не запрещает регистрацию через API.
4. Netlify → существующий сайт reliable-unicorn-7ce032 → Project configuration → Build & deploy → Continuous deployment → Repository → Link repository → GitHub → Yndsik/sait. Production branch: `main`; build command: пусто; publish directory: `.`. Наличие автоматического деплоя не подтверждено: доступа к настройкам Netlify в этой сессии нет.
5. Netlify → Project configuration → Environment variables → Add a variable: `SUPABASE_URL` = URL текущего проекта, `SUPABASE_PUBLISHABLE_KEY` = его публичный publishable key, `OWNER_USER_ID` = тот же UID. Доступность переменных: Functions, включая Deploy Previews. `service_role`, пароли и Twitch secrets не нужны.
6. Открой Deploy Preview для PR, войди существующим аккаунтом и проверь: поиск Signalis; поиск 1262350; подробности и скриншоты; добавление в Wishlist; повторное добавление; изменение статуса/оценки/заметок; перезагрузка; выход/вход. Индикатор должен показать «В облаке ✓». Затем проверь то же на втором устройстве.
7. В SQL Editor проверь `select policyname, roles, qual, with_check from pg_policies where tablename='user_workspaces';`. Без входа запрос REST к таблице не должен раскрывать данные. Другой пользователь не должен получать строки и записывать workspace. Пользователь, отличный от OWNER_USER_ID, должен получать 403 от Steam Function.
8. После успешной проверки слей PR. Netlify автоматически опубликует main, если шаг 4 выполнен. Не загружай вручную только index.html: функции входят в Git-развёртывание.

## Что хранится

Игры и дополнительные поля остаются в существующем JSON `user_workspaces.data.games`; отдельная таблица игр не нужна для этого этапа. Supabase Auth и существующая синхронизация сохранены. До применения миграции RLS и реальное сохранение не подтверждены.

## Steam и Hidden Gems

Сервер загружает по 12 результатов Steam Store, детали и агрегированные отзывы. Кэш в памяти экземпляра: поиск 5 минут, детали/отзывы 15 минут, максимум 500 записей; холодный запуск сбрасывает кэш. Запросы деталей ограничены тремя параллельными вызовами. Для большого каталога потребуется постоянный серверный индекс и распределённый лимитер.

Score = 100 × нижняя граница Wilson (95%) × (0.7 + 0.3 × неизвестность). Неизвестность = max(0, 1 − log10(число отзывов)/5). При менее 10 отзывах score отсутствует. Число отзывов — косвенный сигнал известности, не число игроков. Значения источников не выдумываются. Поиск Hidden Gems стартует с выдачи Steam по отзывам; фильтры/сортировка действуют только на уже загруженные страницы, поэтому глобальная полнота подборки не гарантирована.

Длительность, фактические игроки онлайн, Twitch и глобальный индекс каталога пока не подключены. Полноценный календарь UTC+5, повторы, история аналитики и дополнительные связи относятся к следующим этапам.
