# Визуальное обновление

В боковое меню добавлена обычная доступная ссылка «Приложение Android» на /android.html. На телефоне перед переходом закрывается drawer; каталог APK и его контрольная сумма не меняются.

Обновлены оформление главной, приветствие из собственного профиля (с экранированием), фон, карточки статистики, декоративная композиция YNDSI, акценты навигации, формы и кнопки. Поля/данные не заменяются демонстрационными значениями. В декоративной части убран прежний индекс 01/05, поскольку карусель не реализована.

Новый design-ui.js анимирует только смену раздела, а не каждое обновление сообщений/сохранение формы. Анимация декора приостанавливается на скрытой вкладке. prefers-reduced-motion отключает движения, включая при изменении настройки во время открытой страницы.

Проверено: npm run build/check/test; встроенный JS; Chromium с изолированным подставным провайдером Auth и пустым workspace на 390/1280 px. Проверены отсутствие горизонтального overflow, мобильное раскрытие/прокрутка меню, переход по Android-ссылке, отключение движений и отсутствие JS-ошибок. Это проверка интерфейса на тестовых данных, не тест живых пользовательских аккаунтов или настоящего iPhone.
