# Установка на iPhone

Открыть https://reliable-unicorn-7ce032.netlify.app/ в Safari → Поделиться → На экран Домой → включить «Открывать как веб-приложение», если переключатель доступен → Добавить. Запустить иконку YNDSI. При необходимости войти в существующий аккаунт. В настройках сайта есть инструкция установки.

Это PWA, без App Store. Та же база и функции сайта; интернет нужен для входа, переписки и синхронизации. Уведомления при закрытом приложении пока не реализованы. Разрешения микрофона и камеры могут запрашиваться отдельно от Safari. Удаление иконки не удаляет аккаунт. Можно продолжить пользоваться обычным сайтом.

Manifest, PNG 180/192/512, standalone и safe-area адаптация. Service worker всегда запрашивает страницы из сети, не сохраняет приватные страницы/API/вложения; кэширует лишь общую offline.html. При потере сети показывает эту страницу. Работа офлайн с личными данными не заявляется. Уже существующий per-account localStorage приложения не меняется.

Проверено автоматически: политика service worker, метаданные и размеры иконок; остальные тесты проекта. Фактическую установку, разрешения, клавиатуру и вырез экрана нужно проверить на iPhone пользователя. Проверить вход, ЛС, отправку голосового/видео, возврат из фона и повторное открытие после обновления сайта.
