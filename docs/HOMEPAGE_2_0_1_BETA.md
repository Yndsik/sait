# Главная RIVLO — 2.0.1 бета

## Область изменений

Новый первый экран видит посетитель без входа. Рабочая главная вошедшего пользователя сохранена. Supabase, серверные функции, схема данных, обработчики входа/регистрации и набор маршрутов не меняются. Зависимости не добавлены. Android APK остаётся 2.0.0; 2.0.1 бета — версия веб-интерфейса.

Порядок: hero → три карточки пользы → локальный черновик при выборе → переключаемые макеты интерфейса → существующие игровые новости → Android с пометкой «Бета» → подвал. В русской оболочке убраны англоязычные слоганы. Копирайт и локальный режим используют существующий `ynI18n` и `i18n-dictionary.js`.

## Локальный режим

Кнопка «Попробовать без регистрации» раскрывает форму внутри той же главной, не меняя маршрут и не открывая авторизацию. Название, дата, время, план, ссылки на клипы и разбор сохраняются по кнопке только в `localStorage` под ключом `rivlo_local_stream_v1`. Нет обращений к Supabase, изменения `db` или присвоения `workspaceAccess`. Формат содержит только ограниченные по длине строки. Данные выводятся с экранированием, ссылки не исполняются и не загружаются.

Черновик не публикуется и не переносится в аккаунт автоматически. Смена языка сохраняет введённый текст в памяти; перезагрузка восстанавливает последнее явное сохранение. При недоступном хранилище пользователь видит сообщение, а черновик живёт до закрытия страницы.

## Замена макетов скриншотами

В `landing-ui.js` функция `mock()` содержит три `<figure data-preview-slot="plan|schedule|review">`. Каждый макет явно помечен демонстрационным. Внутренний блок `.landing-mock-content` можно заменить на `<img class="landing-screenshot" src="/имя-файла.webp" alt="Описание интерфейса">`. Добавить файл в список `assets` в `scripts/build.cjs`; новых библиотек не нужно. Сохранить подпись, переключатели и доступный alt.

## Как проверить

1. `npm run check`, `npm run build:cloudflare`, `npm test`.
2. Открыть сайт без входа на ширине 360 px: первым идёт hero, три карточки и макеты; блока APK в первом экране нет; нет горизонтальной прокрутки.
3. Нажать «Попробовать без регистрации», заполнить и сохранить форму, перезагрузить страницу и снова открыть локальный режим. Данные сохраняются, окно входа не открывается.
4. Переключить RU/EN, включая каждый макет и локальную форму. Введённые значения не переводятся и не теряются.
5. Нажать «Войти»: откроется прежняя форма. После входа доступна прежняя рабочая главная; выход не переносит локальные данные в облако.
6. Проверить Android-блок внизу и ссылку на существующий APK 2.0.0. В «Обновлениях» отображается 2.0.1 бета; автоматическое объявление для этой беты выключено, чтобы не перекрывать первый экран.

Проверено Chromium на 360, 390, 768 и 1440 px, в RU/EN, с уменьшением движения; локальное сохранение/перезагрузка и обычный вход проверены с локальным подставным провайдером. Реальные аккаунты и production-база не изменялись.
