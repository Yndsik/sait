# Профиль, приватность и поиск · 2.0.0

Профиль теперь открывается как личная страница: обложка, аватарка, описание, реальные счётчики, ближайшие планы и игровая полка. Карандаш раскрывает существующий редактор. Сохранение возвращает к просмотру, закрытие редактора отменяет изменения. При первом входе редактор остаётся обязательным. ID не меняется.

Привязка Twitch, разрешение на поиск и заявка на подтверждение канала перенесены в **Приватность**. Редактор имени, аватарки, часового пояса и обложки открывается только через профиль. Привязка Twitch использует OAuth, не произвольный ник; поиск сопоставляет постоянный числовой ID Twitch с Auth Identity.

В карточке другого пользователя не отображается его постоянный ID. Свой ID виден самому владельцу профиля, его можно добровольно передать другу. ID остаётся техническим идентификатором для сообщений/подписок и присутствует в API и разметке кнопок: это не пароль и не секрет авторизации. Полностью исключить его из API потребовало бы отдельной миграции всех связей; текущая задача меняет видимость в интерфейсе, сохраняя действующий поиск по ID.

В друзьях два режима поиска: точный ID или канал Twitch. Для канала проверяется добровольно опубликованная OAuth-связь с RIVLO. Нет связи/профиль скрыт — нет кнопки добавления; при сбое проверки не утверждаем, что аккаунта нет. Отправка заявки происходит только по явному нажатию, согласие на дружбу и ограничения доступа остаются серверными. Поиск в своём круге фильтрует по имени.

**Режим разработчика** доступен только владельцу сайта в общих настройках. Состояние переключателя хранится отдельно на этом устройстве для текущего пользователя. Раздел показывает безопасные проверки доступности, версию и инструменты модерации. Заявки перенесены сюда из редактора профиля. Серверные RPC по-прежнему проверяют владельца; переключатель не выдаёт никаких прав. Секреты, переписка и почта не входят в диагностику. Пометка **BETA · internal** есть только в этом закрытом разделе, публичная версия остаётся 2.0.0 без бета-баннера.

Глобальный поиск Twitch требует настройки Cloudflare и SQL 016: [инструкция](TWITCH_SETUP.md). До настройки есть понятное состояние недоступности и поиск существующих профилей RIVLO. Реальный OAuth и живые результаты Twitch требуют ключей владельца; автоматические проверки используют имитацию Twitch API, реальный Worker и PostgreSQL-совместимую базу.
