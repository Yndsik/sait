# Предпочтения по развитию RIVLO

Пользователь разрешил самостоятельно выбирать небольшие улучшения дизайна и удобства во всех вкладках, без отдельного согласования. После выполнения нужно явно отметить, какие идеи добавлены от себя. Если идея не понравится, убрать её по просьбе пользователя.

Публиковать завершённые изменения разрешено без дополнительного подтверждения. Пока все изменения и заметки относятся к версии **2.0.0**; не создавать отдельные версии и повторные всплывающие объявления для каждой мелочи.

Приватность, постоянные ID, дружба, сохранённые данные и реальные статусы не должны ухудшаться ради оформления. Новые локальные настройки разделять между аккаунтами. Не выдавать декоративные элементы за реальные метрики. Наличие SQL/ключей и внешних настроек проверять отдельно от публикации интерфейса.

Пользователю не понравилась вкладка «Пульс» — удалить и не возвращать. Он предпочитает заметное обновление всех существующих вкладок, красивые единообразные иконки и полезные небольшие возможности без лишнего раздела обзора.

Пользователь явно разрешил отдельную версию **2.0.1 бета** для нового первого экрана и локального пробного режима. Изменения ограничены фронтендом; Supabase, авторизацию и роутинг не менять. По просьбе пользователя эту версию можно откатить к предыдущей 2.0.0.

Следующая явно разрешённая задача внутри 2.0.1 бета — вход/регистрация через Supabase Twitch рядом с email. Для неё разрешены изменения фронтенд-интеграции Auth; прежний email-вход и локальный режим сохраняются. Новая схема БД не нужна: приватные поля Twitch хранятся в существующем JSON профиля. Секреты настраиваются вручную только в Supabase. Возможность отката интерфейса к 2.0.0 сохраняется.

Пользователь отверг мобильную 2.0.2 и явно попросил откат к 2.0.1 бета. Откат выполнен PR #35. Следующая задача — больше красивых анимаций и улучшений дизайна поверх восстановленной 2.0.1; сразу называть собственные дополнения. Добавление от себя: отдельный выбор спокойных/выразительных дополнительных эффектов. Отвергнутый мобильный слой не возвращать.

Пользователь просит самостоятельно улучшать общение и добавлять собственные идеи, сразу сообщая, что добавлено. Новое дополнение — отдельное отключение звука для выбранного диалога (на этом устройстве, отдельно по аккаунтам). Ответы с цитатами добавляются без миграций, версия остаётся 2.0.1 бета; по просьбе пользователя дополнения убирать.

Уточнение: аудитория — стримеры, зрители и люди, ищущие авторов. Основной адрес остаётся https://yndsi-streamer-hub.pages.dev/ . Развивать Dota-статистику в духе Dotabuff, не выдавать lookup ID за проверенную принадлежность профиля, не выдумывать данные или MMR.
