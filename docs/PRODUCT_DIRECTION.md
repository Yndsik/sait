# Предпочтения по развитию RIVLO

Пользователь разрешил самостоятельно выбирать небольшие улучшения дизайна и удобства во всех вкладках, без отдельного согласования. После выполнения нужно явно отметить, какие идеи добавлены от себя. Если идея не понравится, убрать её по просьбе пользователя.

Публиковать завершённые изменения разрешено без дополнительного подтверждения. Пока все изменения и заметки относятся к версии **2.0.0**; не создавать отдельные версии и повторные всплывающие объявления для каждой мелочи.

Приватность, постоянные ID, дружба, сохранённые данные и реальные статусы не должны ухудшаться ради оформления. Новые локальные настройки разделять между аккаунтами. Не выдавать декоративные элементы за реальные метрики. Наличие SQL/ключей и внешних настроек проверять отдельно от публикации интерфейса.
