# Подписки, подтверждение стримера и онлайн

После публикации выполните в Supabase SQL Editor миграции:
1. `supabase/migrations/202611080012_creator_subscriptions.sql` после существующих 001–009.
2. `supabase/migrations/202611080013_online_count.sql` после 009.

SQL не выполняется автоматически при публикации сайта. До подключения новых RPC галочки и подписки недоступны, онлайн отображает «—», а не выдуманное число.

## Проверка канала владельцем сайта

Пользователь получает случайный код в настройках профиля и размещает его в публичном описании своего Twitch/YouTube-канала. SQL сохраняет заявку; галочка сама себе не выдаётся. В SQL Editor список заявок:

```sql
select p.code,p.name,v.channel,v.proof,v.requested_at
from yndsi_private.creator_verifications v
join yndsi_private.social_profiles p using(user_id)
where not v.verified order by v.requested_at;
```

Вручную откройте **точный URL из заявки**, убедитесь, что код виден в описании именно этого канала. Проверяется владение каналом, не личность/качество контента. После проверки скопируйте постоянный ID и точные URL/код в запрос (замените значения):

```sql
update yndsi_private.creator_verifications v
set verified=true,reviewed_at=now()
from yndsi_private.social_profiles p
where p.user_id=v.user_id and p.code='ID_ПОЛЬЗОВАТЕЛЯ'
and v.channel='ПРОВЕРЕННЫЙ_URL' and v.proof='ПРОВЕРЕННЫЙ_КОД';
```

Если изменился URL или код, запрос не подтверждает старую заявку. Отозвать галочку: аналогичный запрос с `verified=false`. Не выдавайте клиенту service_role или доступ к приватным таблицам. Менять verified может только администратор базы. Смена канала пользователем сбрасывает проверку.

## Напоминания

Подписаться можно на опубликованное расписание из профиля пользователя, дружба и галочка не обязательны. До 200 подписок на аккаунт. Списки подписчиков/подписок не публикуются. Скрытые расписания и заблокированные связи исключаются сервером. Даты передаются в UTC, сравнение с сегодняшним днём происходит на устройстве в выбранном пользователем часовом поясе; координаты не запрашиваются.

Проверка раз в минуту при открытом видимом сайте. Одно напоминание на эфир на данном браузере/аккаунте, повторное изменение эфира создаёт обновлённое напоминание. Баннер и опциональное системное уведомление. Это **не push при закрытом сайте** и не гарантия точной доставки. Для фоновой доставки нужен Web Push backend/планировщик; текущая версия его не содержит. Звук включён по умолчанию, доступен после взаимодействия с браузером; выключается в настройках уведомлений.

## Онлайн и скидки

Онлайн — агрегат аккаунтов с видимым статусом и свежим heartbeat из 009. Гости не учитываются; скрывшие статус исключены; идентификаторы не возвращаются. Скидки приходят из Steam featured specials, регион KZ, цены в валюте ответа. Источник может быть недоступен — тогда показана ошибка, не фиктивные акции. Ссылки ведут на официальные скидки и новости распродаж Steam.
