# Быстрее каждый день · RIVLO 2.0.0

Самостоятельно добавленные удобства:

- Быстрый переход: кнопка «Найти» над страницей, «Быстрый переход» в боковом меню или Ctrl/⌘ K. Разделы доступны гостям согласно прежним правам. В своём аккаунте можно искать названия своих игр, заметок, задач и планов эфиров; выбор открывает существующую карточку/редактор.
- До четырёх закреплённых разделов: звезда над страницей, компактные кнопки в боковом меню. Сохраняются на этом устройстве отдельно для каждого аккаунта. В хранилище записываются только известные ключи разделов, а не названия личных записей или переписка.
- В переписке: кнопка поиска в шапке. Ищет только среди уже загруженных текстовых сообщений, показывает совпадения и переносит к выбранному сообщению. Не скрывает сообщения, не изменяет историю или правила прочтения. Черновик сохраняется.
- В задачах: фильтры «Все / В работе / Готово» и число видимых задач. Это только представление, данные задач не меняются.
- В календаре: кнопка «Сегодня», с учётом личного часового пояса.
- В пустых списках: понятный следующий шаг и кнопка действия; карточки заметок доступны с клавиатуры.

Обновлены заголовки, карточки, активная навигация, фильтры новостей, календарь, задачи, заметки, библиотека, профиль, приватность, настройки, стримеры и чат. Поддерживаются обе темы, компактность и уменьшение движения. Поиск использует plain text, работает локально и не вызывает внешние поисковые API. Результаты и строка поиска очищаются при закрытии/смене аккаунта; гостям личные записи не индексируются.

Новые функции этого пакета не требуют SQL или ключей. Для уникальных @ников из предыдущего пакета по-прежнему нужен SQL 017, для Twitch — его отдельная настройка. Ни один из этих шагов не выполняется публикацией файлов сайта.
