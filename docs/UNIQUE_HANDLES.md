# Уникальный @ник, поиск и профиль по ссылке · 2.0.0

## Подключение

В Supabase → SQL Editor выполните [SQL 017](../supabase/migrations/202611080017_unique_handles.sql). Прямая ссылка: https://supabase.com/dashboard/project/ougbjjfrxfokyqqriqtx/sql/new

Нужны существующие миграции профилей, 008 (лимиты/доступ), 012 (подписки/подтверждения). Twitch, его ключи, SQL 015/016 для поиска по @нику не требуются. Миграция повторно запускается безопасно. Старые постоянные ID и обычные имена не меняются; уникальные ники никому автоматически не присваиваются.

## Для пользователя

1. Мой профиль → карандаш → «Уникальный @ник».
2. Выберите 3–24 символа: первая — латинская буква, далее латинские буквы, цифры и подчёркивание. Например, `danger_lexa`. Регистр не различается.
3. Включите «Разрешить поиск по @нику и просмотр по ссылке», если хотите быть доступны друзьям. До этого профиль не становится публичным.
4. Нажмите **Сохранить @ник**. Это отдельная настройка; обычное имя/аватарка сохраняются существующей кнопкой профиля.
5. На странице профиля появится «Поделиться профилем». Ссылка: `https://yndsi-streamer-hub.pages.dev/?u=danger_lexa`.
6. В друзьях → «По нику» можно вставить точный @ник или эту ссылку. ID и Twitch остаются дополнительными вариантами.

Обычное имя может повторяться. Уникальность @ника обеспечивается индексом базы, включая два одновременных запроса; клиентская проверка не является источником истины. Служебные названия зарезервированы. Смена @ника меняет ссылку: прежняя ссылка больше не ведёт на этот профиль.

## Приватность

В Приватности → «Кто может тебя найти» можно отключить поиск и публичную ссылку одновременно. Друзья и чаты сохраняются; прежний поиск по добровольно переданному ID продолжает работать. Это отдельный переключатель от поиска по Twitch.

Гость по ссылке видит только добровольно опубликованные имя, аватарку, обложку, описание, проверенный статус стримера, число подписчиков и уже опубликованное расписание. Для заявки в друзья и сообщений нужен вход. Нет почты, геопозиции, часового пояса, заметок, задач, списка друзей или всей библиотеки. Чужой постоянный ID не отображается, но остаётся техническим идентификатором в API; это не секрет авторизации. Блокировки учитываются для вошедшего пользователя. Публичный профиль по определению доступен гостям, когда видимость включена.

Проверки выполняются узкими SECURITY DEFINER RPC с пустым search_path. Таблицы остаются закрытыми для anon/authenticated; изменение @ника допускается только для auth.uid(). Прямой запрос ссылок не даёт прав на переписку. Нет поиска по префиксу и нет публичного списка всех аккаунтов.

До выполнения SQL 017 интерфейс показывает, что @ники настраиваются, и оставляет остальные функции профиля доступными. Публикация сайта сама SQL не запускает.

## Дизайн и сообщения

Общий стиль обновлён для главной, расписания, библиотеки, Wishlist, прохождений, заметок, задач, стримов, статистики, профиля, приватности, настроек, стримеров и истории обновлений. Сохранены обе темы, компактность и отключение движения. На узких экранах исправлено переполнение переключателей календаря.

Чат получил разделители дат по приватному часовому поясу зрителя, группы последовательных сообщений и кнопку перехода вниз. При фоновом обновлении сохраняется положение чтения, при подгрузке истории учитывается изменение высоты. Текст, записи, подписанные медиа-ссылки, реальные статусы прочтения и серверные права не изменены.
