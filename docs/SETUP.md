# Подключение с iPhone

Изменения подготовлены для существующего сайта. До настройки окружения серверный Steam API закрыт и возвращает 503. Steam Web API Key не требуется: отзывы загружаются анонимно через IUserReviewsService/GetAppReviews/v1, а поиск и карточки — через Store endpoints. Они не гарантируют SLA; ошибки показываются в интерфейсе.

1. Supabase → Authentication → Users → открой свой существующий аккаунт → скопируй **User UID**. Не создавай новый аккаунт, чтобы сохранить связь с данными.
2. Supabase → SQL Editor → New query: вставь `supabase/migrations/202611060001_owner_workspace.sql`, замени `REPLACE_WITH_OWNER_UUID` своим UID и нажми Run. Скрипт сохраняет данные, заменяет политики таблицы `user_workspaces` доступом только владельца. Если таблицы нет, транзакция завершится ошибкой: сначала нужно проверить фактическую схему, не создавать пустую замену.
3. Supabase → Authentication → Sign In / Providers → Email: выключи **Allow new users to sign up**. Удаление кнопки в интерфейсе само по себе не запрещает регистрацию через API.
4. Netlify → существующий сайт reliable-unicorn-7ce032 → Project configuration → Build & deploy → Continuous deployment → Repository → Link repository → GitHub → Yndsik/sait. Production branch: `main`; build command: пусто; publish directory: `.`. Наличие автоматического деплоя не подтверждено: доступа к настройкам Netlify в этой сессии нет.
5. Netlify → Project configuration → Environment variables → Add a variable: `SUPABASE_URL` = URL текущего проекта, `SUPABASE_PUBLISHABLE_KEY` = его публичный publishable key, `OWNER_USER_ID` = тот же UID. Доступность переменных: Functions, включая Deploy Previews. `service_role`, пароли и Twitch secrets не нужны.
6. Открой Deploy Preview для PR, войди существующим аккаунтом и проверь: поиск Signalis; поиск 1262350; подробности и скриншоты; добавление в Wishlist; повторное добавление; изменение статуса/оценки/заметок; перезагрузка; выход/вход. Индикатор должен показать «В облаке ✓». Затем проверь то же на втором устройстве.
7. В SQL Editor проверь `select policyname, roles, qual, with_check from pg_policies where tablename='user_workspaces';`. Без входа запрос REST к таблице не должен раскрывать данные. Другой пользователь не должен получать строки и записывать workspace. Пользователь, отличный от OWNER_USER_ID, должен получать 403 от Steam Function.
8. После успешной проверки слей PR. Netlify автоматически опубликует main, если шаг 4 выполнен. Не загружай вручную только index.html: функции входят в Git-развёртывание.

## Что хранится

Игры и дополнительные поля остаются в существующем JSON `user_workspaces.data.games`; отдельная таблица игр не нужна для этого этапа. Supabase Auth и существующая синхронизация сохранены. До применения миграции RLS и реальное сохранение не подтверждены.

## Steam и Hidden Gems

Сервер загружает по 12 результатов Steam Store, детали и агрегированные отзывы. Кэш в памяти экземпляра: поиск 5 минут, детали/отзывы 15 минут, максимум 500 записей; холодный запуск сбрасывает кэш. Запросы деталей ограничены тремя параллельными вызовами. Для большого каталога потребуется постоянный серверный индекс и распределённый лимитер.

Score = 100 × нижняя граница Wilson (95%) × (0.7 + 0.3 × неизвестность). Неизвестность = max(0, 1 − log10(число отзывов)/5). При менее 10 отзывах score отсутствует. Число отзывов — косвенный сигнал известности, не число игроков. Значения источников не выдумываются. Поиск Hidden Gems стартует с выдачи Steam по отзывам; фильтры/сортировка действуют только на уже загруженные страницы, поэтому глобальная полнота подборки не гарантирована.

Длительность, фактические игроки онлайн, Twitch и глобальный индекс каталога пока не подключены. Полноценный календарь UTC+5, повторы, история аналитики и дополнительные связи относятся к следующим этапам.

Обновление отзывов: старый Store /appreviews помечен Valve как deprecated. Используем https://api.steampowered.com/IUserReviewsService/GetAppReviews/v1/ с input_json, review_type=0, purchase_type=1 и languages=["all"]. Поддерживается обёртка response. Источник: https://partner.steamgames.com/doc/webapi/IUserReviewsService. При HTTP 429 отображаем недоступность; обходов лимитов и подставных оценок нет.

## Рекомендации и скрытые жемчужины

Кнопка «Рекомендуем тебе» выбирает наиболее выраженный жанр из библиотеки; избранное имеет больший вес, оценка 8–10 усиливает сигнал. Игры с оценкой ниже 5 и брошенные не формируют вкусы. При недостатке данных показывается общая подборка. Направление можно сменить вручную. Личные заметки, оценки и библиотека не отправляются в Steam: передаётся только выбранный ID тега.

Выдача строится из новых популярных релизов Steam (filter=popularnew), максимум по 12 кандидатов на страницу. Уже добавленные игры, будущие релизы, игры без статистики и с менее 20 отзывами исключаются; минимальный рейтинг рекомендаций — 80%. Для скрытых жемчужин минимум 50 отзывов и 85%, верхняя граница по умолчанию 5000 (настраивается). Подборки не покрывают весь каталог и не предсказывают интерес зрителей. Объяснение отбора показано на каждой карточке. При пустой выдаче можно загрузить следующую страницу или сменить направление. Steam tag/genre соответствуют широким направлениям, не точному сходству игровых механик.

## Игры и расписание

Кнопка «Запланировать стрим» доступна в выдаче Steam, рекомендациях и личной библиотеке/Wishlist. При выборе из Steam игра сначала добавляется в библиотеку; отмена формы не удаляет её. Форма позволяет выбрать существующую игру или оставить свободный текст. Сохраняются gameId и запасное название game; после удаления игры запись стрима сохраняет название.

Дата/время вводятся по Asia/Atyrau (UTC+5), поле startsAt сохраняется ISO UTC, timeZone — Asia/Atyrau. Поля date/time сохранены для совместимости с текущим календарём. Старые записи читаются как время Атырау и получают startsAt при следующем сохранении; старые записи без времени остаются в списке и требуют редактирования. Главная показывает ближайший будущий запланированный стрим по точному времени начала. При сохранении стрима статус игры «Хочу пройти»/«В планах» меняется на «Скоро на стриме»; активные и завершённые прохождения сохраняют статус.

Проверка на iPhone: из игры создать стрим на завтра в 20:00, сохранить, проверить расписание и главную; изменить время; обновить страницу и проверить сохранение; удалить тестовый стрим через форму. Попробовать 02:30 — в UTC дата должна быть предыдущей (21:30Z). Данные идут через существующую синхронизацию user_workspaces; новых SQL и переменных не требуется. Повторы стримов пока не реализованы.

## Профиль и оформление

Настройки профиля открываются нажатием аватарки вверху или через «Настройки». Имя (до 32 символов), описание (до 160), акцент и аватар сохраняются в user_workspaces.data.profile; миграции и Storage bucket не требуются. Старые workspace без profile получают имя YNDSI и стандартную иконку. Это настройки отображения, они не меняют Supabase email/пароль и права владельца.

Иконка: JPEG/PNG/WebP до 8 МБ, центральная квадратная обрезка 256×256, кодирование WebP, максимум 180000 символов data URL. SVG, внешние ссылки и другие форматы не принимаются. Фото хранится внутри закрытого JSON workspace и входит в экспорт. Изменения применяются после «Сохранить профиль», кнопка отмены возвращает сохранённый вариант. Поле профиля изменяется через существующий save()/Supabase sync; нужно дождаться статуса «В облаке ✓».

Проверка на iPhone: нажать аватарку, изменить имя и описание, выбрать акцент, загрузить фото, сохранить; обновить страницу и открыть настройки повторно. Проверить удаление иконки, отмену несохранённых изменений и экспорт/импорт. Облачное восстановление профиля требует проверки владельцем; локальные тесты не заменяют её. CSS поддерживает prefers-reduced-motion.
