# RIVLO: имя и журнал версий

С версии сайта 2.0.0 бренд YNDSI заменён на RIVLO. Домен Cloudflare Pages остаётся прежним. Ключи локальных данных `yndsi_*`, постоянные ID, функции Supabase и Android applicationId `app.yndsi.hub` намеренно сохранены, чтобы переименование не сбросило данные и аккаунты. Android APK 1.1 подписана и не пересобиралась: системное название и иконка уже скачанного APK остаются прежними; сайт внутри использует новый бренд. Страница скачивания явно предупреждает об этом. PWA-манифест, новая установка с сайта, favicon и apple touch icon используют RIVLO. Системы могут не сразу обновлять иконку уже установленной PWA.

## Новая версия

Добавьте запись в начало `releases.js`: неизменяемый semver `version`, дата `YYYY-MM-DD`, RU/EN заголовок, описание, sections и ограничения note. Не меняйте номер старого релиза, чтобы повторно не показывать его. Это публичные редакционные записи; имена пользователей и приватные данные сюда не добавляются. Начальная запись 2.0.0 объединяет текущие изменения; произвольные старые номера версий не выдуманы.

Раздел «Обновления» доступен в боковом меню и гостям. На входе в новую версию появляется краткое окно. Оно ждёт закрытия входа/редактора/другого диалога, не мешает первому заполнению профиля, поддерживает Escape, клавиатуру и прокрутку небольшого экрана. После показа отмечается прочитанным. Ручной просмотр журнала доступен всегда.

После SQL 014 RPC `yn_release_claim` атомарно отмечает показ версии на аккаунт: несколько вкладок/устройств не получают повторный автопоказ. Гости и аккаунты до подключения SQL используют локальное хранилище — один показ на браузер. Если хранилище заблокировано, отметка остаётся только до закрытия страницы. У зарегистрированного пользователя недоступность БД допускает локальный fallback, чтобы журнал продолжал работать. Между устройствами такая временная отметка не синхронизируется до восстановления сервиса.

## Motion

В `rivlo.css` и `rivlo-motion.js`: последовательное появление hero-текста, ограниченный по времени световой проход и плавающий знак, мягкий tilt только для точного указателя и появления блоков при прокрутке. История чата и счётчики не переанимируются при опросе. `prefers-reduced-motion`, выключатель анимаций и скрытие вкладки учитываются. Нет фонового автозвука: уведомления играют только после взаимодействия с браузером.

## Общая игра

Карточка в чате разбирает сохранённое текстовое сообщение предыдущей версии. Steam App ID валидируется; обложка берётся с фиксированного Steam CDN, ссылка на Steam строится из ID. Кнопка открывает точный App ID в библиотеке RIVLO, разворачивает подробности и не добавляет игру автоматически. Ручная игра без Steam App ID открывает поиск по названию, без фиктивной обложки. Названия экранируются; произвольные присланные URL не загружаются.
