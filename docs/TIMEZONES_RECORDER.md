# Часовые пояса и запись сообщений

После миграций 001–005 выполните целиком `supabase/migrations/202611070006_user_timezones.sql` в Supabase SQL Editor. Она добавляет часовой пояс и расширяет существующие RPC. ID аккаунтов и токены расписаний сохраняются. Старые клиенты с тремя аргументами `yn_social_profile` продолжают работать.

При первом входе после обновления пояс определяется по устройству и сохраняется в профиле. Последующие входы с другого устройства его не заменяют. Изменить пояс можно в настройках профиля, включая первый вход. Все новые эфиры сохраняют абсолютное время UTC. Смена пояса меняет отображение, а не момент начала. Старые записи без UTC и собственного пояса трактуются как Asia/Atyrau, как до обновления. Несуществующее время при переводе часов отклоняется; для повторяющегося часа можно выбрать первое или второе повторение.

Профиль показывает до шести ближайших опубликованных эфиров в поясе посетителя. Личные планы, заметки и неопубликованные эфиры туда не попадают. Для публикации остаётся необходим явный выбор эфиров в настройках. Публичная страница позволяет выбрать пояс устройства, автора или UTC.

Голосовые: индикатор уровня микрофона, таймер, пауза/продолжение, повторная запись; проигрыватель с перемоткой и скоростью. Во время записи столбики отражают уровень звука; в проигрывателе они декоративные. Лимит активной записи: 120 секунд голосового и 30 секунд видео, паузы не учитываются.

Кружки: предпросмотр до начала записи, переключение камер, круговой индикатор времени, повторная запись и развёрнутое видео. Во время записи переключение использует стабильную дорожку canvas при поддержке браузером. Иначе переключение доступно перед записью. Отмена, выход из чата и смена аккаунта освобождают камеру/микрофон. При уходе приложения в фон активная запись останавливается.

Автоматические проверки: `npm test`, `npm run check`. SQL регрессия: `supabase/tests/user_timezones.sql` (синтетические аккаунты, ROLLBACK). SQL и реальные устройства в среде разработки не запускались.

Перед выпуском проверить на iPhone Safari и Android Chrome: разрешения, смену камер до/во время записи, паузу, отмену, фон, отправку и воспроизведение между устройствами. Проверить два аккаунта с разными поясами, изменение пояса после сохранения эфира, показ только выбранных эфиров в профиле и отзыв публикации.

## Отдельные личные сообщения

«Сообщения» открываются из бокового меню и верхней панели. На широком экране список диалогов и переписка расположены рядом; до 850 px показывается список или выбранная переписка с кнопкой «Диалоги». Поиск работает по имени/ID, список включает принятых друзей; непрочитанные диалоги идут первыми. Черновики сохраняются в памяти до выхода из аккаунта. Уведомления открывают раздел сообщений. На странице друзей остаются поиск и управление заявками. Дополнительного SQL для этого интерфейса не нужно.

Проверки перед выпуском: открыть переписку из друзей, профиля и уведомления; вернуться к диалогам на телефоне; сохранить черновик при переходах; убедиться, что просмотр страницы друзей не отмечает сообщения прочитанными. Запись вложения должна останавливаться при выходе из раздела сообщений.
