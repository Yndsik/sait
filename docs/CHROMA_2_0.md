# RIVLO 2.0.0 — CHROMA

«Пульс» удалён из навигации, поиска, рендера и публикуемой сборки по просьбе пользователя. Старый модуль оставлен пустым для совместимости истории репозитория. Не возвращать этот раздел.

Обновлено оформление всех 16 основных вкладок: общая оболочка, SVG-иконки, контрастные заголовки, библиотека и Wishlist, календарь, друзья, сообщения, заметки, задачи, стримы, статистика, стримеры, профиль, приватность, настройки, история обновлений и главная. Геометрическая графика декоративная, не изображает реальные метрики. Анимации короткие, учитывают настройку уменьшения движения.

Добавлены от себя:

- Цветовая студия: Электрик, Закат и Мята. Быстрый доступ из верхней панели и выбор в настройках. Выбор хранится только в браузере отдельно для каждого аккаунта и гостя. Никакие имена, тексты сообщений или профильные данные не сохраняются вместе с цветом.
- Просторная переписка: кнопка разворота в заголовке чата скрывает навигацию и список диалогов. Черновик и текущие сообщения остаются в том же DOM. Выход той же кнопкой или Escape; режим сбрасывается при переходе и выходе из аккаунта.

Изменения входят в существующую 2.0.0; нового уведомления о версии нет. SQL и новые внешние ключи не требуются. Настройки приватности, ID, права доступа и публикация расписания не изменяются.
